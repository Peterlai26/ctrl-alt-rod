# Ctrl+Alt+รอด — ชุดไฟล์เว็บแอพ (PWA)

อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นเว็บ แล้วคนเล่นจะกด "ติดตั้ง" เป็นแอพบนมือถือหรือคอมได้เลย ไม่ต้องผ่าน App Store / Play Store

## ไฟล์ในชุด
| ไฟล์ | หน้าที่ |
|---|---|
| index.html | ตัวเกม |
| manifest.webmanifest | บอกเครื่องว่าเป็นแอพ: ชื่อ ไอคอน เปิดเต็มจอ แนวนอน |
| sw.js | ตัวเก็บเกมไว้ในเครื่อง ทำให้เล่นออฟไลน์ได้ |
| icon-*.png, apple-touch-icon.png, favicon-*.png | ไอคอนแอพ |

ต้องอัปโหลดทุกไฟล์ไว้ในโฟลเดอร์เดียวกัน ห้ามเปลี่ยนชื่อไฟล์

## ขึ้นเว็บด้วย GitHub Pages (ฟรี)
1. สมัคร/ล็อกอิน github.com
2. กด **New repository** ตั้งชื่อ เช่น `ctrl-alt-rod` เลือก **Public** แล้วกด Create
3. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ใส่ กด **Commit changes**
4. ไปที่ **Settings → Pages** ช่อง Branch เลือก `main` และ `/ (root)` แล้วกด Save
5. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ctrl-alt-rod/`

ทางเลือกที่ง่ายกว่า: เข้า app.netlify.com/drop แล้วลากทั้งโฟลเดอร์ใส่ ได้ลิงก์ทันที

เว็บต้องเป็น **https** เท่านั้น (GitHub Pages และ Netlify เป็นให้อยู่แล้ว) ถ้าเปิดไฟล์จากเครื่องตรง ๆ จะติดตั้งเป็นแอพไม่ได้

## วิธีติดตั้งเป็นแอพ
- **Android (Chrome):** เปิดลิงก์ → กดปุ่ม **เริ่ม** ในเกม → **ติดตั้งเป็นแอพ** (หรือเมนู ⋮ → ติดตั้งแอป) แอพจะเปิดเต็มจอเป็นแนวนอนอัตโนมัติ
- **iPhone / iPad (Safari):** เปิดลิงก์ใน Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** (ในเกมมีวิธีบอกในเมนู ติดตั้งเป็นแอพ) iOS ล็อกแนวนอนให้ไม่ได้ ต้องหมุนเครื่องเอง
- **คอม (Chrome / Edge):** กดไอคอนติดตั้งที่ช่อง URL หรือเมนู ติดตั้งเป็นแอพ ในเกม

ติดตั้งแล้วเล่นออฟไลน์ได้ เซฟเก็บอยู่ในเครื่องของคนเล่นแต่ละคน

## เวลาอัปเดตเกม
อัปโหลด `index.html` และ `sw.js` ชุดใหม่ทับของเดิม (sw.js ทุกชุดมีเลขเวอร์ชันใหม่ในตัว) คนที่ติดตั้งไว้จะได้เวอร์ชันใหม่ตอนเปิดแอพครั้งถัดไปที่มีเน็ต ส่วนเซฟเกมจะไม่หาย

## ข้อควรรู้
- ถ้าคนเล่นลบแอพหรือล้างข้อมูลเบราว์เซอร์ เซฟจะหาย
- ฟอนต์โหลดจาก Google Fonts ตอนเปิดครั้งแรก แล้วเก็บไว้ในเครื่อง ถ้าครั้งแรกออฟไลน์จะใช้ฟอนต์ของเครื่องแทน (เกมยังเล่นได้ปกติ)
