# Ctrl+Alt+รอด — ชุดไฟล์เว็บแอพ (PWA)

อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นเว็บ แล้วคนเล่นจะกด "ติดตั้ง" เป็นแอพบนมือถือหรือคอมได้เลย ไม่ต้องผ่าน App Store / Play Store

## ไฟล์ในชุด
| ไฟล์ | หน้าที่ |
|---|---|
| index.html | ตัวเกม |
| manifest.webmanifest | บอกเครื่องว่าเป็นแอพ: ชื่อ ไอคอน เปิดเต็มจอ แนวนอน |
| sw.js | ตัวเก็บเกมไว้ในเครื่อง ทำให้เล่นออฟไลน์ได้ |
| icon-*.png, apple-touch-icon.png, favicon-*.png | ไอคอนแอพ |
| fonts/ | ฟอนต์ Anuphan กับ Chakra Petch (ลิขสิทธิ์ SIL OFL) |
| tools/smoke-test.js | สคริปต์ทดสอบเล่นผ่านอัตโนมัติ (ไม่ได้ใช้ตอนเล่น) |

ต้องอัปโหลดทุกไฟล์ไว้ในโฟลเดอร์เดียวกัน ห้ามเปลี่ยนชื่อไฟล์

## เว็บของเกม
เล่นได้ที่ **https://peterlai26.github.io/ctrl-alt-rod/** (GitHub Pages จาก branch `main` โฟลเดอร์ root)

พอ push เข้า `main` แล้ว GitHub Pages จะอัปเดตเว็บเองในราว 1–2 นาที

เว็บต้องเป็น **https** เท่านั้น (GitHub Pages เป็นให้อยู่แล้ว) ถ้าเปิดไฟล์จากเครื่องตรง ๆ จะติดตั้งเป็นแอพไม่ได้

## วิธีติดตั้งเป็นแอพ
- **Android (Chrome):** เปิดลิงก์ → กดปุ่ม **เริ่ม** ในเกม → **ติดตั้งเป็นแอพ** (หรือเมนู ⋮ → ติดตั้งแอป) แอพจะเปิดเต็มจอเป็นแนวนอนอัตโนมัติ
- **iPhone / iPad (Safari):** เปิดลิงก์ใน Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** (ในเกมมีวิธีบอกในเมนู ติดตั้งเป็นแอพ) iOS ล็อกแนวนอนให้ไม่ได้ ต้องหมุนเครื่องเอง
- **คอม (Chrome / Edge):** กดไอคอนติดตั้งที่ช่อง URL หรือเมนู ติดตั้งเป็นแอพ ในเกม

ติดตั้งแล้วเล่นออฟไลน์ได้ เซฟเก็บอยู่ในเครื่องของคนเล่นแต่ละคน

## เวลาอัปเดตเกม
แก้ `index.html` แล้วเปลี่ยนเลข `VERSION` ใน `sw.js` ทุกครั้ง คนที่ติดตั้งไว้จะได้เวอร์ชันใหม่ตอนเปิดแอพครั้งถัดไปที่มีเน็ต ส่วนเซฟเกมจะไม่หาย

## ข้อควรรู้
- ถ้าคนเล่นลบแอพหรือล้างข้อมูลเบราว์เซอร์ เซฟจะหาย
- ฟอนต์อยู่ในโฟลเดอร์ `fonts/` และถูกเก็บลงเครื่องตั้งแต่เปิดเกมครั้งแรก เล่นออฟไลน์ได้โดยฟอนต์ไม่เพี้ยน
- ถ้าย้ายเว็บไปที่อยู่ใหม่ (เช่น โดเมนของตัวเอง) เซฟเกมและแอพที่ติดตั้งไว้จากที่อยู่เดิมจะไม่ตามไปด้วย

## ทดสอบก่อนอัปเดต
```
npm i --no-save playwright
npx playwright install chromium
node tools/smoke-test.js
```
สคริปต์จะเล่นผ่านตั้งแต่หน้าเริ่มจนถึงวันที่ 3 บนจอแนวนอนสองขนาด แล้วบอกว่ามี error หรือไม่
